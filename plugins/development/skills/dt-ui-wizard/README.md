# DT UI Wizard

Strato design system guide for building Dynatrace AppEngine UIs. Enforces Strato-first component selection, design token usage, and visual consistency with the Dynatrace platform.

## What it covers

- Component decision ladder (when to use Strato vs build custom)
- All ~80 Strato components with import paths, key props, and usage notes
- Design tokens for colors, spacing, typography, borders
- Layout hierarchy and responsive breakpoints
- App structure, navigation patterns
- Data visualization component selection
- Status/health indicators, filtering, error messages, AI presence
- Content writing rules for Dynatrace apps

## Usage

```
/development:dt-ui-wizard
```

Invoke when writing any React UI for a dt-app project.
