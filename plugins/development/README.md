# Development Plugin

Claude Code skills for building Dynatrace AppEngine apps.

## Skills

| Skill | Description |
|---|---|
| [dt-ui-wizard](skills/dt-ui-wizard/README.md) | Strato design system guide — component selection, tokens, layout, patterns for dt-app UI development |

## Installation

```
claude /plugin marketplace add brandonsturrock/brandon-insights
claude /plugin install development@brandon-insights
```

Reload after install:

```
claude /reload-plugins
```
